# Product Inventory & Analytics Dashboard

An interactive product inventory dashboard built using JavaScript, HTML, and CSS. This project demonstrates core JavaScript concepts through product management, inventory analytics, and financial calculations.

## Features

- Add products with name and price
- Automatically assign product categories
- Display inventory and total inventory value
- Filter affordable products
- Generate formatted product reports
- Calculate tax, discounts, and discounted inventory value
- Responsive dashboard interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js (for running the console-based capstone project)
- Git and GitHub
- Vercel

## How to Run the Console Project

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the capstone project:

node capstone-project.js

5. Enter a product name and price when prompted.
